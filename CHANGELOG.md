# DevMail — простой IMAP/SMTP клиент в стиле WhatsApp

Пакет: `com.dsh.mail` · versionName 2.13 (versionCode 24) · minSdk 26 (Android 8+) · targetSdk 35
Файл: `/sdcard/Download/Dev/DevMail.apk` (он же `Test/DevMail.apk`, `Test/mail/../DevMail.apk`)

Иконка — неоновый конверт в киберпанк-стиле.

## Как установить

1. Откройте файл-менеджер → **Загрузки** → `DevMail.apk`.
2. Нажмите «Установить»; если система попросит — разрешите установку из этого источника.
   Версия 1.1 ставится поверх старой «Почты» (тот же пакет) — аккаунты сохраняются.
3. Запустите приложение **DevMail**.

Установить из консоли нельзя: оболочка без прав INSTALL_PACKAGES, поэтому только вручную.

## Настройка аккаунта

В приложении: вкладка **Настройки** (внизу справа) → **＋ Добавить аккаунт**.

Поля:

| Поле | Что писать |
|---|---|
| Название | любое, например «Работа» |
| Адрес почты | `you@example.com` |
| IMAP сервер / порт | хост и порт, SSL-галочка |
| SMTP сервер / порт | хост и порт, SSL-галочка |
| Логин | обычно полный адрес |
| Пароль | обычный пароль или пароль приложения |
| Проверка почты | число минут вручную: `0` — только по кнопке ⟳, `15`…`1440` — фоновая проверка |

Кнопка **Проверить** проверяет IMAP и SMTP по очереди и показывает текст ошибки сервера.
Кнопка **Сохранить** сохраняет; пароль шифруется (AES/GCM, ключ в Android Keystore).

Готовые настройки популярных серверов:

- Gmail: `imap.gmail.com:993` SSL, `smtp.gmail.com:465` SSL. Нужен «пароль приложения»
  (Google → Безопасность → Двухэтапная проверка → Пароли приложений).
- Mail.ru: `imap.mail.ru:993`, `smtp.mail.ru:465`, SSL, логин — полный адрес.
- Яндекс: `imap.yandex.ru:993`, `smtp.yandex.ru:465`, SSL; при 2FA — пароль приложения.
- Рамблер: `imap.rambler.ru:993`, `smtp.rambler.ru:465`.

Аккаунтов можно добавить сколько угодно; в списке чатов под именем показывается,
в какой ящик пришло письмо (если аккаунтов больше одного).

## Как пользоваться

- **Чаты** — письма сгруппированы по собеседнику: аватар с инициалами, имя, время,
  последняя строка, зелёный счётчик непрочитанных. Тап — открыть переписку.
- В переписке — пузыри: слева серые (входящие), справа зелёные (исходящие),
  даты-разделители «Сегодня / Вчера / 12 октября 2026».
- Ответ: поле внизу → ➤. Тема подставляется из переписки, с префиксом `Re:`.
- Новое письмо: **✚** в шапке. Там же выбор ящика-отправителя.
- Вложение: **📎** → системный выбор файла (без разрешений на память) → отправка.
  Полученное вложение: тап по пузырю → список вложений → «Загрузить» → «Открыть с помощью».
- **⟳** — синхронизировать все аккаунты сейчас.
- **Настройки** → чипы «Ночь / День / Киберпанк» — смена темы; вкладка и состояние сохраняются.
- Входящая почта приходит уведомлением, если включена фоновая проверка; из шторки можно
  ответить сразу (поле ответа в карточке) или отметить «Прочитано».
- **🔍** — поиск по именам, адресам, темам и тексту писем (без учёта регистра).
- Долгое нажатие на чат (или меню в переписке) — **закрепить**, **без звука**, переименовать,
  отметить прочитанным, удалить локально. Закреплённые чаты держатся сверху.
- В переписке меню ⋮ → **Экспорт переписки**: весь диалог сохраняется в `.txt` через
  системный выбор файла (включая вложения и цитаты).

## Ограничения (важно)

- **Фон минимум 15 минут** — ограничение Android (JobScheduler). Если ввели 1–14, фон всё равно
  будет раз в 15 минут; `0` = без фоновой проверки (только при открытии и по кнопке ⟳).
  Значение больше 1440 обрезается до суток.
- **Три темы**: Ночь (по умолчанию), День, Киберпанк — переключаются в настройках, применяются сразу.
- HTML-письмо показывается форматированным текстом (`Html.fromHtml`), без картинок и скриптов.
- Синхронизируются только **INBOX и папка «Отправленные»** (ищется автоматически:
  `Sent`, `Sent Items`, `Отправленные`, `[Gmail]/Sent Mail`).
- За одно обновление берутся **последние 25 писем** из папки; уже прочитанные не дублируются.
- Локальная копия письма сохраняется для повторного открытия вложений (до 5 МБ);
  большие письма хранятся без raw-копии — вложения из них скачать нельзя.
- Счётчик непрочитанных считается после синхронизации; отметка «прочитано» локальная
  и на сервер не отправляется.

## Что внутри

`src/com/dsh/mail/`
- `MainActivity` — список чатов / аккаунты, темы, синхронизация
- `Themes`, `Ui` — выбор темы, отступы под статус-бар/навигацию, аватары, даты
- `ChatActivity` — переписка в стиле WhatsApp, отправка, вложения
- `ComposeActivity` — новое письмо
- `AccountEditActivity` — настройка серверов, проверка, интервал, удаление
- `MailService` — IMAP-синк, разбор MIME, SMTP-отправка, проверка настроек
- `Db`, `Crypto`, `Account`, `MailMessage`, `AttachmentInfo`, `ChatItem`
- `LiveSync`, `LiveService` — живое IMAP-соединение: IMAP IDLE для мгновенной доставки
  (с откатом на опрос новых UID), foreground-сервис в фоне
- `MailActionReceiver` — быстрый ответ и «Прочитано» из уведомления
- `SyncJobService`, `Schedule`, `Notifier` — страховочная проверка раз в 15+ минут
- `AttachProvider` — раздача вложений другим приложениям по `content://`

## 2.4 — папки по флагам RFC и живые соединения

- Открытый чат обновляется сам: держим IMAP-сеанс и раз в 3 секунды спрашиваем
  только диапазон новых UID (`UID FETCH last+1:*`), без повторного логина.
- Свёрнутое приложение продолжает получать почту: foreground-сервис, тихое
  уведомление «Почта проверяется в реальном времени» с кнопкой «Отключить»,
  опрос раз в 30 секунд (экономия батареи).
- HTML-письма показываются форматированным текстом (`Html.fromHtml`, режим
  LEGACY), ссылки кликабельны; картинки и скрипты не загружаются; копирование
  по-прежнему отдаёт чистый текст.

## 2.5 — настройка фоновой проверки и живой чат при «вручную»

- В настройках аккаунта вместо числа минут — выбор: «Только вручную»,
  «Мгновенно (постоянное соединение)», «Каждые 5 / 15 / 30 / 60 минут»
  (значение `checkMin`: `0`, `-1`, `N`).
- Открытый чат обновляется всегда, даже если выбрано «только вручную»:
  живое соединение работает, пока хоть один экран приложения на переднем плане.
- Открытие чата будит соединение (`LiveSync.poke()`), плюс страховочная полная
  синхронизация раз в 2 минуты (в фоне — раз в 10).
- «Мгновенно» и интервалы меньше 15 минут обслуживает foreground-сервис,
  15 минут и больше — `JobScheduler` (без постоянного уведомления).

## 2.7 — имена, фоновое изображение и прозрачность

- Локальное имя чата: длинный тап по чату → «Переименовать» (или ⋮ в открытом
  чате). Хранится в `chat_names`, сервер и адрес не затрагиваются, есть «Сбросить».
- Фон чата: ⋮ в открытом чате → «Фон чата из галереи»; картинка копируется внутрь
  приложения (`files/bg`), обрезается по экрану, поверх — затемняющая подложка.
  «Убрать фон» возвращает обычный вид.
- Пузыри сообщений стали чуть прозрачными (альфа ~92–95 % в цветах `c_bubble_*`),
  сквозь них видно фон; текст остаётся читаемым за счёт подложки.

## 2.8 — английский язык

- В настройках появился раздел «ЯЗЫК»: два чипа — **Русский** и **English**;
  выбранный подсвечивается акцентом. Переключение мгновенное (`recreate()`),
  выбор хранится в `ui/lang` и переживает перезапуск.
- Весь интерфейс переводится на месте: тексты в коде обёрнуты в `L.t(...)`,
  подписи и подсказки из разметки переводятся обходом дерева View
  (`L.localize`) сразу после `setContentView`. Словарь — 203 строки в `L.java`.
- Локаль приложения (`Locale.setDefault`) тоже переключается, поэтому даты и
  системные диалоги идут на выбранном языке. Письма, имена папок и содержимое
  ящика не переводятся — только интерфейс.
- «Журнал отладки» и системный канал уведомлений берут название из словаря,
  так что после переключения языка они тоже меняются.

## 3.0 — «Поделиться» в DevMail

- Приложение появилось в системном меню «Поделиться»: `ACTION_SEND` и
  `ACTION_SEND_MULTIPLE` для `*/*`. Присланные файлы копируются во временную папку,
  затем выбираешь получателя — список контактов с поиском или «Новый адрес…», —
  и открывается письмо с уже вложенным файлом. Если поделились текстом без файла,
  он подставляется в тело письма.
- Композер принимает несколько вложений сразу: имена показываются в строке вложений,
  отправка собирает multipart со всеми частями, локальная копия в «Отправленных»
  получает все вложения.
- Версия: `DevMail 3.0 · 30`, лицензия MIT, исходники подготовлены для GitHub.

## 2.16 — карточка контакта, аватарки, чистка кеша

- **Кружок аккаунтов больше не сливается с фоном**: для «все аккаунты» — прозрачный
  круг с акцентной обводкой и символом `@`, у конкретного ящика — цветной круг с буквой.
- **Карточка собеседника** (тап по аватарке или по имени/адресу в шапке переписки):
  фото 96 dp (или круг с инициалами), имя, e-mail и действия — «Написать»,
  «Копировать адрес», «Удалить фото».
- **Аватарки контактов задаются вручную**: тап по фото в карточке → выбор картинки из
  галереи. Фото обрезается в круг (512 px, JPEG/PNG, EXIF-поворот учтён) и хранится в
  `files/avatars/<md5 e-mail>`; показывается в шапке переписки и в списке чатов.
  Почта аватарки не отдаёт, поэтому это единственный надёжный способ.
- **Настройки**: список аккаунтов переехал на отдельный экран «Мои аккаунты» (`AccountsActivity`),
  в настройках осталась строка с их количеством. Добавлена строка **«Очистить кеш вложений»**
  с текущим размером: удаляет скачанные вложения, копии для «поделиться» и временные
  файлы (`files/att`, `files/out`, `cacheDir`), сбрасывает пути в БД. Письма и переписка
  остаются, вложения качаются заново из сохранённого `.eml`.
- **Просмотр фото**: щипок и двойной тап для масштаба (до 8×), панорамирование пальцем,
  двойной тап по увеличенному — возврат к «вписать в экран». Подсказка внизу экрана.
- **Отладка по умолчанию выключена** (`ui/debug_chat=false`): журнал появляется в списке
  только после тройного тапа по строке версии в настройках (повторный тройной тап — выкл).
- Версия: `DevMail 2.16 · 27`.

## 2.15 — кнопки-иконки, селектор аккаунтов

- **Иконки вместо эмодзи** во всех шапках: `ic_search`, `ic_refresh`, `ic_plus`,
  `ic_check`, `ic_more`, `ic_trash`, `ic_close`, `ic_back`, `ic_copy`, `ic_arrow_up`,
  `ic_arrow_down`, `ic_send`, `ic_attach` (векторные `drawable`, 24 dp). Кнопки получили
  `IconBtnAccent` (градиент как у «новое письмо», заливка `btn_accent`, тинт `c_on_accent`),
  `IconBtnPlain` и `IconBtnDanger` (удаление в `btn_danger`).
- **Кружок аккаунта слева в шапке списка чатов**: буква выбранного ящика, цвет — из
  палитры `Ui.palette(index)`, так что у каждого аккаунта свой. Нажатие открывает
  селектор: «Все аккаунты» + список ящиков (цветной кружок, e-mail, галочка текущего).
- **Фильтр по аккаунту**: выбор сохраняется в `ui/acct` (`-1` — все), список чатов
  фильтруется в SQL (`Db.chatsFor`, чтобы лимит 300 не съедал историю), поиск — в памяти.
  Непрочитанные в подписи вкладки считаются по видимым чатам, метка аккаунта в строке
  красится тем же цветом, что и кружок в шапке.
- Смена аккаунта сбрасывает поиск; пустой список подписан «В этом аккаунте пока нет писем».
- Версия в настройках: `DevMail 2.15 · 26`.

## 2.14 — вложения по нажатию, картинки в чате, автозагрузка

- **Автозагрузка сообщений** в настройках: «Все» / «До 160 КБ, изображения плохого
  качества» / «До 640 КБ, изображения среднего качества» / «До 5 МБ» / «До 25 МБ».
  Выбор хранится в `ui/auto_dl` (`AttachStore.level`), по умолчанию 640 КБ.
- **Скачивание по нажатию**: сообщение целиком лежит в `files/raw/*.eml`, поэтому тап
  по вложению распаковывает нужную MIME-часть (`MailService.extractPart`) в `files/att/`
  без обращения к серверу. Если raw не сохранился (письмо больше лимита) — `refetchRaw`
  догружает письмо с IMAP по UID и запоминает новый путь в базе.
- **Картинки прямо в пузыре**: `MsgAdapter.bindAttachments` рисует превью (200 dp,
  до 260 dp по высоте, `att_img_bg` 14 dp) из `LruCache` на 8 МБ; у остальных вложений —
  чип «📎 имя · размер · ⬇ Загрузить». Пустое тело у письма-картинки скрывается.
- **Просмотр фото** — `PhotoActivity`: чёрный фон, декодирование с `inSampleSize`
  в фоновом потоке, ✕ и имя файла.
- **Сжатие под лимит**: `AttachStore.compress` — 720 px / q55 → 160 КБ,
  1280 px / q72 → 640 КБ, WEBP при альфе или PNG, иначе JPEG. Для «5/25 МБ» и «Все»
  файл копируется как есть.
- **Отправленные** тоже получают превью: `insertSent` → `AttachStore.storeLocal`.
- **Чистка**: при удалении чата файлы `files/att` удаляются (`attachmentPaths`).
- БД `mail.db` 8 → 9: у `attachments` появились `path`, `state`, `width`, `height`
  (`ALTER TABLE`, данные сохраняются).
- Версия в настройках: `DevMail 2.14 · 25`.

## 2.13 — свайпы, мультивыбор, плавающая дата, поиск в переписке

- **Свайпы в списке чатов.** Вправо — «прочитано», влево — «удалить» (цветная подложка
  с иконкой и подписью, порог + вибро). Жест — `ListSwipe` на самом `ListView`: строки
  в `ListView` не получают `MOVE`, пока не съедят `DOWN`, а это ломает тапы и долгие нажатия.
- **Мультивыбор** долгим нажатием: ✓ отметить прочитанными, ⋮ меню одного чата, 🗑 удалить
  локально с подтверждением; выход — ✕ или «назад».
- **Черновик в списке**: «Черновик: …» акцентным курсивом вместо превью.
- **Умное время**: `HH:mm` → «вчера» → «пн» (2–6 дней) → `d MMM` → `dd.MM.yy`.
- **Плавающая дата** в переписке: показывает день верхнего сообщения, гаснет через 1.2 с,
  тап — `DatePickerDialog` и переход к выбранному дню.
- **Автопрокрутка к «Новые сообщения»** при открытии; кнопка «↓» со счётчиком писем ниже
  экрана; свайп пузыря вправо — ответ с цитатой.
- **Поиск в переписке** (🔍 в шапке чата): фильтр по теме/телу/превью/цитате, ↑/↓ по
  совпадениям, подсветка текущего, счётчик «N/M».
- **Память позиции чтения** (`ui/scroll_<thread>`) и разделитель «Новые сообщения»
  в виде полупрозрачной акцентной полосы со стрелкой.
- Версия в настройках: `DevMail 2.13 · 24`.

## 2.12 — IDLE, ответ из шторки, поиск, закрепление и экспорт

- **IMAP IDLE.** Если сервер объявляет IDLE, живое соединение не опрашивает почту, а ждёт
  команду сервера: письмо приходит мгновенно, в том числе когда приложение свёрнуто.
  Серверам без IDLE оставляем прежний опрос (3 с на экране, интервал из настроек в фоне).
  Смена аккаунта/остановка сервиса снимает IDLE (`idleAbort`), соединение закрывается чисто.
- **Ответ из шторки.** В карточке уведомления две кнопки: «Ответить» (прямой ввод текста
  через `RemoteInput`, письмо уходит с темой `Re: …` тем же SMTP-путём, что и из чата)
  и «Прочитано» (счётчик и карточка убираются). Ответ работает, даже если приложение убито.
- **Поиск.** 🔍 в шапке открывает строку поиска; ищет по имени, адресу, теме, превью
  и телу писем без учёта регистра (включая кириллицу), список фильтруется по мере ввода.
- **Закрепление и «без звука».** Меню чата: закрепить/открепить, выключить/включить звук.
  Закреплённые — сверху (журнал отладки всегда первый), у заглушённых карточка уведомления
  не создаётся. Состояние в таблице `chat_flags` (база v8, без потери данных).
- **Разделитель «Новые сообщения».** При открытии чата перед первым письмом, пришедшим
  после прошлого просмотра, показывается чип «Новые сообщения» (по `reads.last_id`).
- **Экспорт переписки.** Меню ⋮ → «Экспорт переписки»: весь диалог с датами, темами,
  цитатами и списком вложений сохраняется в `.txt` через `ACTION_CREATE_DOCUMENT`
  (имя файла — `<чат>-yyyyMMdd-HHmm.txt`).

## 2.11 — версия в настройках и скрываемый журнал отладки

- Внизу настроек показывается версия приложения (`DevMail 2.12 · 23`).
- **Три тапа по версии** включают и выключают «Журнал отладки» в списке чатов.
  Состояние запоминается в `ui/debug_chat`; при включении чат создаётся сразу,
  при выключении пропадает из списка (сообщения и логи остаются в базе).
- Убраны упоминания сторонних мессенджеров из кода и документации.

## 2.10 — уведомления по чатам

- В шторке теперь отдельная карточка на каждый чат с новыми письмами: заголовок — имя
  собеседника (или локальное имя чата), текст — последнее входящее письмо, подпись — ящик,
  в углу — число новых. Если чатов несколько, сверху сводка «Новая почта · N».
- Нажатие на карточку открывает **сразу этот чат**, а не общий список; «назад» возвращает
  к списку (список кладётся в стек под чат).
- Открыли чат — его карточка пропадает, сводка пересобирается по оставшимся.
- Пока приложение на экране, уведомления не дублируются (счётчики и так видны).
- Канал уведомлений пересоздан (`mail2`, IMPORTANCE_HIGH): всплывающие уведомления (heads-up)
  и вибрация.

## 2.9 — «новые» вместо «непрочитанных» и новый дизайн

- Счётчик теперь считает **новые письма в диалоге**, а не непрочитанные: сравнивается
  id последнего просмотренного письма, поэтому чужая отметка `\Seen`, прочтение в другом
  клиенте и расхождение часов сервера больше не «съедают» цифру. Хранится в
  `reads.last_id` (миграция базы v7, без потери данных).
- Открыл чат — счётчик обнулился; пришло письмо — цифра появилась в списке и на вкладке.
  Первая синхронизация нового аккаунта считает загруженную историю просмотренной,
  чтобы не показывать сразу весь ящик.
- Дизайн переработан: список чатов — карточки со скруглением 18dp и разделителями,
  аватары 46dp, жирное имя и подсветка фона у чатов с новыми письмами, бейдж-градиент
  с «99+».
- Вместо овальных кнопок — градиентные плитки: нижние вкладки стали сегмент-контролом
  с подсвеченным активным сегментом, кнопки в шапке — мягкие плитки (главная — градиент),
  чипы темы и языка заливаются градиентом при выборе.
- Поле ввода сообщения — «пилюля» 22dp, кнопка отправки — круглая градиентная с тенью,
  кнопка вложения — плитка 44dp.
- Пузыри сообщений: скругление 18dp с «хвостиком» 6dp и лёгкой тенью, аккуратные цитаты,
  увеличенные отступы. Пустой список получил круглый акцентный значок конверта.
- Экраны аккаунта и письма: заполненные и «призрачные» (outlined) кнопки вместо
  однотипных прямоугольников, поля с большими скруглениями.

## Пересборка

```bash
cd /data/user/0/com.deepseek.harness/files/Test
bash build_mail.sh      # → DevMail.apk
cp DevMail.apk /sdcard/Download/DevMail.apk
```

Сборка: `aapt2 compile/link` → `javac` → `d8` (классы + `javax.mail-1.6.2` + `activation-1.1.1`)
→ добавление `classes.dex` → копирование `META-INF/javamail.*`, `mailcap` из jar внутрь APK
(иначе JavaMail не находит провайдеров на Android) → `apksigner sign` (v2/v3).
